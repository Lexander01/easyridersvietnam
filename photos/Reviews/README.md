# Review photos

Photos in this folder are shown in the "Traveller Reviews" section on the home page.

How to add a photo:

1. Name the files `review1.jpg`, `review2.jpg`, `review3.jpg`, ... in order, **with no gaps in the numbering** (loading stops at the first missing number).
2. Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`.
3. Upload the file to this folder — the home page picks it up automatically, no code changes needed.

If this folder has no photos, the reviews section is hidden on the home page.
